# Akapulu Labs

Live AI avatars on real-time video calls. Docs: https://docs.akapulu.com. Docs MCP: `akapulu-docs`. REST: Bearer `AKAPULU_API_KEY` on `https://akapulu.com/api/`.

Follow https://docs.akapulu.com/agent-setup.md for install (skills, MCP, API key).

**Build path.** Install [`pipecat-akapulu`](https://github.com/Akapulu/pipecat-akapulu) (`uv add` / `pip install`). Your Pipecat bot sends speech through `AkapuluAvatar`. Guide: https://docs.akapulu.com/guides/calls/your-bot. Example: https://github.com/Akapulu/akapulu-examples.

**Quick try.** Hosted link: avatar + system prompt + **This is AI** toggle → URL → **Start Call**. Guide: https://docs.akapulu.com/guides/calls/hosted-links.

API key: https://akapulu.com/api-keys → `AKAPULU_API_KEY`.
